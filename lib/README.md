# MenuLib reference

Place the `MenuLib.dll` from the official **REPOModding-MenuLib 2.6.0** package here before building for R.E.P.O. 0.5.0. The plugin GUID remains `nickklmao.menulib` after the package-author migration.
It is a build reference with `Private=false`; it is not copied into the Stage Flux package.
The binary is excluded from Git. Install MenuLib separately through the mod manager.
