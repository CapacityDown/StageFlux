# Stage Flux

A host-only R.E.P.O. mod with 46 configurable stage events and an in-game Events menu.

- [Player guide and complete event catalog (English / 日本語)](package/README.md)
- [Changelog](package/CHANGELOG.md)
- [Report a problem on GitHub Issues](https://github.com/CapacityDown/StageFlux/issues)
- [Development and verification](DEVELOPMENT.md)
- [Download on Thunderstore](https://thunderstore.io/c/repo/p/CapackMods/StageFlux/)

Only the host needs Stage Flux for gameplay effects. Players who install the mod can also use the event HUD and Events menu. RoleShuffle and Elite Enemy Variants remain optional.

Source version: **4.3.0**.

## Questions and bug reports / お問い合わせ・不具合報告

Please use [GitHub Issues](https://github.com/CapacityDown/StageFlux/issues) for questions, bug reports, or feedback. A GitHub account is required to post. Include reproduction steps and, if available, a reviewed report from **Events → Tools → Report a Problem**. Reports are never uploaded automatically.

ご質問、不具合報告、ご意見は [GitHub Issues](https://github.com/CapacityDown/StageFlux/issues) からお送りください。投稿にはGitHubアカウントが必要です。再現手順と、可能であれば **Events → Tools → Report a Problem** で作成して内容を確認したレポートを添付してください。自動送信は行いません。

Game assemblies, local configuration, logs, generated reports, build output, and release ZIPs are intentionally excluded from this repository.
